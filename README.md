# myexpensesapp

My Expenses is a simple, privacy-focused Android expense tracker. Record expenses, manage budgets, analyze spending, organize categories, track groceries, restore deleted entries, and export or back up your data. Built with Kotlin and Jetpack Compose, it focuses on a clean experience with local-first data management, no account, and no ads.

## ✨ Highlights

- 🔒 **Privacy first** — local-first data, no account, no ads, no tracking
- 💸 Budgets, custom categories and spending analysis
- 🛒 Smart grocery tracking
- ♻️ Restore deleted entries from the recycle bin
- 💾 Backup & export your data anytime
